# @nosam/deploy-core

Shared deployment contracts for Nosam runtimes and deployment adapters. Includes manifests, progress events, routing rules, resource plans, and SQL and Durable Object migration metadata.

This package works in Node.js and Cloudflare Workers. To deploy an application, use the `nosam` CLI.

## Documentation

See Deployment for deploying an app and Platform Development for building a runtime or adapter.

Read the Nosam documentation online or use the Markdown guides and references in `node_modules/nosam/docs/`, included with the `nosam` package.

# @builtbyfriends/deploy-core

Shared deployment contracts for bwf runtimes and deployment adapters. Includes manifests, progress events, routing rules, resource plans, and SQL and Durable Object migration metadata.

This package works in Node.js and Cloudflare Workers. To deploy an application, use the `bwf` CLI.

## Documentation

See Deployment for deploying an app and Platform Development for building a runtime or adapter.

Read the bwf documentation online or use the Markdown guides and references in `node_modules/@builtbyfriends/bwf/docs/`, included with the `bwf` package.

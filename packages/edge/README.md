# @builtbyfriends/edge

Routing and static asset helpers shared by bwf's direct Cloudflare deployments and platform runtime.

Configure redirects, rewrites, headers, and asset behavior through `bwf.config.ts`.

## Documentation

See Static Assets and the configuration reference.

Read the bwf documentation online or use the Markdown guides and references in `node_modules/@builtbyfriends/bwf/docs/`, included with the `bwf` package.

# create-nosam

Create a full-stack Vite app with Nosam, ready for local development and deployment to Cloudflare.

## Getting Started

Use Node.js 24.22+ or 26.12+:

```sh
npm create nosam@latest my-app
cd my-app
npm run dev
```

Choose Vite+ or Vite, then React, Vue, Svelte, or Solid. Pick a D1, PostgreSQL, MySQL, or Static Pages starter. The wizard installs dependencies and sets up TypeScript and coding agents; choose Cloudflare to deploy to your account, or connect to a team platform.

When you're ready to deploy:

```sh
npx nosam deploy
```

## Documentation

Follow the Quickstart to explore your new app. For an existing Vite app, install `nosam` and run `npx nosam init`.

Read the Nosam documentation online or use the Markdown guides and references in `node_modules/nosam/docs/`, included with the `nosam` package.

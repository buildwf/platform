## Nosam

- This project uses Nosam, a Vite framework for React single-page apps on Cloudflare Workers, with optional file-based API routing and typed backend services.
- Use Nosam's CLI and typed APIs. Before working with Nosam, read the relevant Markdown docs in `node_modules/nosam/docs/`; start with `guide/quickstart.md` for setup and `reference/cli.md` for commands.

# @nosam/deploy-cloudflare

Cloudflare deployment primitives used by the Nosam CLI. Provides Worker configuration reads, uploads, activation, and deployment verification for runtime and adapter authors.

To deploy an application to your Cloudflare account, run `nosam deploy --platform cloudflare`.

## Documentation

See the Cloudflare guide for configuration and credentials, or Platform Development for building a runtime or adapter.

Read the Nosam documentation online or use the Markdown guides and references in `node_modules/nosam/docs/`, included with the `nosam` package.

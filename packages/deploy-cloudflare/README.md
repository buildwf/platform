# @builtbyfriends/deploy-cloudflare

Cloudflare deployment primitives used by the bwf CLI. Provides Worker configuration reads, uploads, activation, and deployment verification for runtime and adapter authors.

To deploy an application to your Cloudflare account, run `bwf deploy --platform cloudflare`.

## Documentation

See the Cloudflare guide for configuration and credentials, or Platform Development for building a runtime or adapter.

Read the bwf documentation online or use the Markdown guides and references in `node_modules/@builtbyfriends/bwf/docs/`, included with the `bwf` package.

## User-Facing Imports {#user-facing-imports}

Import Nosam's app-facing APIs from these paths:

| Import path              | Contents                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `nosam`                   | `nosamPlugin`, handler/type re-exports                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `nosam/handler`           | `defineHandler`, `defineMiddleware`, `basicAuth`, `defineScheduled`, `defineQueue`, types                                                                                                                                                                                                                                                                                                                                                                                      |
| `nosam/auth`              | `defineAuth`, `getUser`, `getSession`, `requireAuth`, `AuthUser`, `AuthSession`, `AuthState`                                                                                                                                                                                                                                                                                                                                                                                   |
| `nosam/client`            | `fetch`, `fetchStream`, `FetchError`, `auth`, `createAuthClient`, `AuthUser`, `AuthSession`, `AuthState`                                                                                                                                                                                                                                                                                                                                                                       |
| `nosam/client/react`      | Same as `nosam/client`, with the React Better Auth client                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `nosam/ws`                | `defineRoom`, `defineWebSocket`, `connect`, WebSocket context and connection types                                                                                                                                                                                                                                                                                                                                                                                             |
| `nosam/durable`           | `defineDurableState`, `defineDurableObject`, typed state/RPC/context/migration types                                                                                                                                                                                                                                                                                                                                                                                           |
| `nosam/sse`               | `eventStream`, `formatSse`, `formatSseText`, `getLastEventId`, `SseStreamClosedError`, SSE message and stream types                                                                                                                                                                                                                                                                                                                                                            |
| `nosam/sse/client`        | `connectEventStream`, browser `EventSource` wrapper types                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `nosam/live`              | `defineLiveStream`, SSE topic fanout runtime types. Server-only.                                                                                                                                                                                                                                                                                                                                                                                                               |
| `nosam/live/client`       | `connectLiveStream`, browser helper for one SSE connection plus POST subscribe/unsubscribe control.                                                                                                                                                                                                                                                                                                                                                                            |
| `nosam/response`          | `convertReturnValue`                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `nosam/validator`         | `runValidation`, `ValidatorSlots`, `HandlerInput`                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `nosam/drizzle-zod`       | Re-exports [`drizzle-zod`](https://orm.drizzle.team/docs/zod) for schema-derived Zod validators for Drizzle tables                                                                                                                                                                                                                                                                                                                                                             |
| `nosam/drizzle-valibot`   | Re-exports [`drizzle-valibot`](https://orm.drizzle.team/docs/valibot) for schema-derived Valibot validators for Drizzle tables                                                                                                                                                                                                                                                                                                                                                 |
| `nosam/drizzle-arktype`   | Re-exports [`drizzle-arktype`](https://orm.drizzle.team/docs/arktype) for schema-derived ArkType validators for Drizzle tables                                                                                                                                                                                                                                                                                                                                                 |
| `nosam/schema-d1`         | Re-exports [`drizzle-orm/sqlite-core`](https://orm.drizzle.team/docs/column-types/sqlite) for D1 table and column builders                                                                                                                                                                                                                                                                                                                                                     |
| `nosam/schema-pg`         | Re-exports [`drizzle-orm/pg-core`](https://orm.drizzle.team/docs/column-types/pg) for PostgreSQL table and column builders                                                                                                                                                                                                                                                                                                                                                     |
| `nosam/schema-mysql`      | Re-exports `drizzle-orm/mysql-core` for MySQL table and column builders                                                                                                                                                                                                                                                                                                                                                                                                        |
| `nosam/database-provider` | `defineDatabaseProvider` and adapter types for `nosam db connect --provider`                                                                                                                                                                                                                                                                                                                                                                                                    |
| `nosam/db`                | `db` (Drizzle D1, PostgreSQL, or MySQL instance for the active dialect), `createDb`, query operators (`eq`, `and`, `or`, `desc`, `like`, `inArray`, etc.)                                                                                                                                                                                                                                                                                                                      |
| `nosam/seed`              | `defineSeed`, `SeedContext`, `SeedFn` for programmatic `nosam db seed` modules                                                                                                                                                                                                                                                                                                                                                                                                  |
| `nosam/kv`                | `kv`, `createKV`, typed KV client/map types                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `nosam/storage`           | `storage`, `createStorage` for the inferred R2 binding or a specific `R2Bucket`                                                                                                                                                                                                                                                                                                                                                                                                |
| `nosam/ai`                | `ai`, `NosamAi`, model input and response types                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `nosam/limits`            | `UsageLimit`, `UsageLimitData`, and `readUsageLimit`. AI and Sandbox limits reject with `UsageLimit`; uncaught limits in Nosam routes return structured HTTP 429 responses.                                                                                                                                                                                                                                                                                                    |
| `nosam/log`               | `logger` structured logging helper                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `nosam/routes`            | [`routeUrl()`](./api/types.md#routeurl-path-options), `RouteDestination`, `RoutePath`, `RouteOptions`, `RouteUrl`, `Href`, `RouteUrlInput`, and generated route maps                                                                                                                                                                                                                                                                                                           |
| `nosam/queues`            | `queues` proxy for sending messages to typed queues                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `nosam/email`             | `sendEmail`, `createEmail`, `defineEmail`, `parseEmail`, `replyEmail`, `MimeError`, `ParseEmailError`, and address, attachment, result, and handler types. See [Email](../guide/email.md).                                                                                                                                                                                                                                                                                     |
| `nosam/email/testing`     | `createEmailTestHarness` and `createInboundTestHarness` to capture sends and deliver test messages to `email/` handlers.                                                                                                                                                                                                                                                                                                                                                       |
| `nosam/sandbox`           | `getSandbox`, `sandbox`, `SandboxLimitError`, `SandboxUnavailableError`, and the SDK 1.0 file, backup, and mount helpers. `getSandbox(id)` resolves a client. Commands, files, port requests, and process completion return promises; limits reject with `SandboxLimitError`, which extends `UsageLimit`. Container state lasts until inactivity (default ten minutes), a crash, or a restart. See [Sandboxes](../guide/sandboxes.md) for the API and deployment requirements. |
| `nosam/env`               | `defineEnv`, `env`, schema helpers (`string`, `number`, `boolean`, `url`, `email`, `oneOf`, `json`), and global Cloudflare env types                                                                                                                                                                                                                                                                                                                                           |

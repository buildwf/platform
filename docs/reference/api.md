## User-Facing Imports {#user-facing-imports}

Import bwf's app-facing APIs from these paths:

| Import path                             | Contents                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `bwf`                                   | `bwfPlugin`, handler/type re-exports                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `@builtbyfriends/bwf/handler`           | `defineHandler`, `defineMiddleware`, `basicAuth`, `defineScheduled`, `defineQueue`, types                                                                                                                                                                                                                                                                                                                                                                                      |
| `@builtbyfriends/bwf/auth`              | `defineAuth`, `getUser`, `getSession`, `requireAuth`, `AuthUser`, `AuthSession`, `AuthState`                                                                                                                                                                                                                                                                                                                                                                                   |
| `@builtbyfriends/bwf/client`            | `fetch`, `fetchStream`, `FetchError`, `auth`, `createAuthClient`, `AuthUser`, `AuthSession`, `AuthState`                                                                                                                                                                                                                                                                                                                                                                       |
| `@builtbyfriends/bwf/client/react`      | Same as `@builtbyfriends/bwf/client`, with the React Better Auth client                                                                                                                                                                                                                                                                                                                                                                                                        |
| `@builtbyfriends/bwf/ws`                | `defineRoom`, `defineWebSocket`, `connect`, WebSocket context and connection types                                                                                                                                                                                                                                                                                                                                                                                             |
| `@builtbyfriends/bwf/durable`           | `defineDurableState`, `defineDurableObject`, typed state/RPC/context/migration types                                                                                                                                                                                                                                                                                                                                                                                           |
| `@builtbyfriends/bwf/sse`               | `eventStream`, `formatSse`, `formatSseText`, `getLastEventId`, `SseStreamClosedError`, SSE message and stream types                                                                                                                                                                                                                                                                                                                                                            |
| `@builtbyfriends/bwf/sse/client`        | `connectEventStream`, browser `EventSource` wrapper types                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `@builtbyfriends/bwf/live`              | `defineLiveStream`, SSE topic fanout runtime types. Server-only.                                                                                                                                                                                                                                                                                                                                                                                                               |
| `@builtbyfriends/bwf/live/client`       | `connectLiveStream`, browser helper for one SSE connection plus POST subscribe/unsubscribe control.                                                                                                                                                                                                                                                                                                                                                                            |
| `@builtbyfriends/bwf/response`          | `convertReturnValue`                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `@builtbyfriends/bwf/validator`         | `runValidation`, `ValidatorSlots`, `HandlerInput`                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `@builtbyfriends/bwf/drizzle-zod`       | Re-exports [`drizzle-zod`](https://orm.drizzle.team/docs/zod) for schema-derived Zod validators for Drizzle tables                                                                                                                                                                                                                                                                                                                                                             |
| `@builtbyfriends/bwf/drizzle-valibot`   | Re-exports [`drizzle-valibot`](https://orm.drizzle.team/docs/valibot) for schema-derived Valibot validators for Drizzle tables                                                                                                                                                                                                                                                                                                                                                 |
| `@builtbyfriends/bwf/drizzle-arktype`   | Re-exports [`drizzle-arktype`](https://orm.drizzle.team/docs/arktype) for schema-derived ArkType validators for Drizzle tables                                                                                                                                                                                                                                                                                                                                                 |
| `@builtbyfriends/bwf/schema-d1`         | Re-exports [`drizzle-orm/sqlite-core`](https://orm.drizzle.team/docs/column-types/sqlite) for D1 table and column builders                                                                                                                                                                                                                                                                                                                                                     |
| `@builtbyfriends/bwf/schema-pg`         | Re-exports [`drizzle-orm/pg-core`](https://orm.drizzle.team/docs/column-types/pg) for PostgreSQL table and column builders                                                                                                                                                                                                                                                                                                                                                     |
| `@builtbyfriends/bwf/schema-mysql`      | Re-exports `drizzle-orm/mysql-core` for MySQL table and column builders                                                                                                                                                                                                                                                                                                                                                                                                        |
| `@builtbyfriends/bwf/database-provider` | `defineDatabaseProvider` and adapter types for `bwf db connect --provider`                                                                                                                                                                                                                                                                                                                                                                                                     |
| `@builtbyfriends/bwf/db`                | `db` (Drizzle D1, PostgreSQL, or MySQL instance for the active dialect), `createDb`, D1 session helpers (`setSession`, `getBookmark`), query operators (`eq`, `and`, `or`, `desc`, `like`, `inArray`, etc.)                                                                                                                                                                                                                                                                    |
| `@builtbyfriends/bwf/seed`              | `defineSeed`, `SeedContext`, `SeedFn` for programmatic `bwf db seed` modules                                                                                                                                                                                                                                                                                                                                                                                                   |
| `@builtbyfriends/bwf/kv`                | `kv`, `createKV`, typed KV client/map types                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `@builtbyfriends/bwf/storage`           | `storage`, `createStorage` for the inferred R2 binding or a specific `R2Bucket`                                                                                                                                                                                                                                                                                                                                                                                                |
| `@builtbyfriends/bwf/ai`                | `ai`, `BwfAi`, model input and response types                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `@builtbyfriends/bwf/limits`            | `UsageLimit`, `UsageLimitData`, and `readUsageLimit`. AI and Sandbox limits reject with `UsageLimit`; uncaught limits in bwf routes return structured HTTP 429 responses.                                                                                                                                                                                                                                                                                                      |
| `@builtbyfriends/bwf/log`               | `logger` structured logging helper                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `@builtbyfriends/bwf/routes`            | [`routeUrl()`](./api/types.md#routeurl-path-options), `RouteDestination`, `RoutePath`, `RouteOptions`, `RouteUrl`, `Href`, `RouteUrlInput`, and generated route maps                                                                                                                                                                                                                                                                                                           |
| `@builtbyfriends/bwf/queues`            | `queues` proxy for sending messages to typed queues                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `@builtbyfriends/bwf/email`             | `sendEmail`, `createEmail`, `defineEmail`, `parseEmail`, `replyEmail`, `MimeError`, `ParseEmailError`, and address, attachment, result, and handler types. See [Email](../guide/email.md).                                                                                                                                                                                                                                                                                     |
| `@builtbyfriends/bwf/email/testing`     | `createEmailTestHarness` and `createInboundTestHarness` to capture sends and deliver test messages to `email/` handlers.                                                                                                                                                                                                                                                                                                                                                       |
| `@builtbyfriends/bwf/sandbox`           | `getSandbox`, `sandbox`, `SandboxLimitError`, `SandboxUnavailableError`, and the SDK 1.0 file, backup, and mount helpers. `getSandbox(id)` resolves a client. Commands, files, port requests, and process completion return promises; limits reject with `SandboxLimitError`, which extends `UsageLimit`. Container state lasts until inactivity (default ten minutes), a crash, or a restart. See [Sandboxes](../guide/sandboxes.md) for the API and deployment requirements. |
| `@builtbyfriends/bwf/env`               | `defineEnv`, `env`, schema helpers (`string`, `number`, `boolean`, `url`, `email`, `oneOf`, `json`), and global Cloudflare env types                                                                                                                                                                                                                                                                                                                                           |
